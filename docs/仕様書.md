# お問い合わせフォーム 仕様書

## 1. 概要

Laravelで構築する「お問い合わせフォーム」アプリケーション。エンドユーザーが問い合わせを送信する「お問い合わせフォーム」と、管理者が問い合わせを確認・管理する「管理ページ」の2つの機能からなる。

## 2. 技術仕様

| 項目 | 内容 |
|---|---|
| フレームワーク | Laravel 13 (PHP) |
| データベース | SQLite |
| コーディング規約 | PSR-12準拠、コメントは日本語 |
| ロケール | `ja`（バリデーションメッセージ等を日本語化） |

## 3. データベース仕様

### 3.1 `contacts` テーブル

問い合わせ内容を保存するテーブル。マイグレーション: `database/migrations/2026_07_27_023018_create_contacts_table.php`

| カラム名 | 型 | 制約 | 説明 |
|---|---|---|---|
| `id` | bigint | 主キー、自動採番 | |
| `name` | string | NOT NULL | 名前 |
| `email` | string | NOT NULL | メールアドレス |
| `subject` | string | NOT NULL | 件名 |
| `body` | text | NOT NULL | 本文 |
| `status` | string | NOT NULL、デフォルト `'new'` | ステータス（`new` / `in_progress` / `resolved`） |
| `created_at` | datetime | | 作成日時（Laravel標準） |
| `updated_at` | datetime | | 更新日時（Laravel標準） |

### 3.2 ステータス定義

`App\Models\Contact` に定数として定義（`statusOptions()` で一覧取得可能）。

| 値 | 表示ラベル | 意味 |
|---|---|---|
| `new` | 新規 | 未対応の問い合わせ（デフォルト値） |
| `in_progress` | 対応中 | 対応着手済みの問い合わせ |
| `resolved` | 解決済み | 対応完了した問い合わせ |

## 4. 機能仕様

### 4.1 お問い合わせフォーム（エンドユーザー向け）

入力 → 確認 → 送信 → 完了 の4画面構成。認証不要で誰でもアクセス可能。

| # | 画面 | メソッド/URL | ルート名 | Controller | View |
|---|---|---|---|---|---|
| 1 | 入力画面 | `GET /contact` | `contact.index` | `ContactController@index` | `contact.index` |
| 2 | 確認画面 | `POST /contact/confirm` | `contact.confirm` | `ContactController@confirm` | `contact.confirm` |
| 3 | 送信（保存） | `POST /contact` | `contact.store` | `ContactController@store` | - |
| 4 | 完了画面 | `GET /contact/complete` | `contact.complete` | `ContactController@complete` | `contact.complete` |

**フロー詳細**

1. **入力画面**: 「名前」「メールアドレス」「件名」「本文」を入力するフォームを表示する。バリデーションエラー発生時は、直前の入力値（`old()`）またはクエリパラメータの値を初期表示する。
2. **確認画面**: 入力画面から送信された内容を `ContactRequest` でバリデーションし、問題なければ入力内容をそのまま表示する確認画面へ遷移する。確認画面には以下の2つの操作がある。
   - **戻る**: `formmethod="GET"` により入力内容をクエリパラメータとして入力画面（`GET /contact`）に渡し、値を保持したまま入力画面に戻る。
   - **送信する**: `POST /contact` に、確認画面の隠しフィールド（hidden input）で保持している入力内容を送信する。
3. **送信（保存）**: `ContactRequest` で再度バリデーションした上で、`Contact::create()` によりDBへ保存する（ステータスはデフォルトの `new`）。保存後、完了画面へリダイレクトする。
4. **完了画面**: 「お問い合わせありがとうございました。」というメッセージを表示する。

**バリデーションルール（`app/Http/Requests/ContactRequest.php`）**

| 項目 | ルール | エラー条件 |
|---|---|---|
| 名前 (`name`) | `required`, `string`, `max:255` | 未入力、または256文字以上 |
| メールアドレス (`email`) | `required`, `email`, `max:255` | 未入力、メール形式でない、または256文字以上 |
| 件名 (`subject`) | `required`, `string`, `max:255` | 未入力、または256文字以上 |
| 本文 (`body`) | `required`, `string`, `max:2000` | 未入力、または2001文字以上 |

バリデーションエラーメッセージは `lang/ja/validation.php` により日本語化されている（属性名も `ContactRequest::attributes()` で日本語表記に変換）。

### 4.2 管理ページ（管理者向け）

問い合わせの一覧・詳細確認・ステータス変更を行う。**認証機能は未実装**（誰でもアクセス可能）。

| # | 画面 | メソッド/URL | ルート名 | Controller | View |
|---|---|---|---|---|---|
| 1 | 一覧画面 | `GET /admin/contacts` | `admin.contacts.index` | `Admin\ContactController@index` | `admin.contacts.index` |
| 2 | 詳細画面 | `GET /admin/contacts/{contact}` | `admin.contacts.show` | `Admin\ContactController@show` | `admin.contacts.show` |
| 3 | ステータス更新 | `PATCH /admin/contacts/{contact}` | `admin.contacts.update` | `Admin\ContactController@update` | - |

**フロー詳細**

1. **一覧画面**: 問い合わせを新着順（`latest()`）に一覧表示する。1ページ20件でページネーションする。各行には受信日時・名前・件名・ステータス（バッジ表示）を表示し、行または名前リンクをクリックすると詳細画面に遷移する。問い合わせが0件の場合は「お問い合わせはまだありません。」と表示する。
2. **詳細画面**: 選択した問い合わせの全項目（受信日時・名前・メールアドレス・件名・本文）を表示する。存在しないIDを指定した場合は404を返す（Laravelのルートモデルバインディングによる）。
3. **ステータス更新**: 詳細画面のドロップダウンリスト（「新規」「対応中」「解決済み」の3択、`Contact::statusOptions()` から生成）で新しいステータスを選択し、「更新」ボタンで `PATCH` リクエストを送信する。更新後は詳細画面にリダイレクトし、「ステータスを更新しました。」というメッセージを表示する。

## 5. 画面共通仕様

- レイアウトは2種類。エンドユーザー向け画面は `resources/views/layouts/app.blade.php`（幅600px、フォーム中心）、管理画面は `resources/views/layouts/admin.blade.php`（幅900px、表組み中心）を使用する。
- いずれもTailwind CSSのビルドに依存せず、レイアウトファイル内に `<style>` タグで直接CSSを定義している（`npm run build` 不要で表示可能）。
